FlowPulse

流动 · 脉冲 —— 为高速精密打印而生的控制固件 Flow · Pulse — control firmware built for high-speed, high-precision printing

一套分体式四层架构，从网页指令到电机脉冲，全链路闭环。Rust 后端大脑 + C 语言裸机固件。支持 SoC 与纯单片机两种落地方案，最低 64 MB 内存即可稳定运行。 A decoupled four-tier architecture covering the full chain from web commands to motor pulses. A Rust control brain plus bare-metal C firmware. Runs on both SoC and pure-MCU boards — stable from just 64 MB RAM.

现状：行业里只有某竹是自研闭源系统，其余厂家基本基于 Klipper。Klipper 用 Python，只能跑在 SoC（Linux），无法在单片机上位机运行；FlowPulse 用 Rust，既能编译到 SoC，也能编译到 ESP32 等单片机。 Today only Bambu ships a self-developed (closed) system; most others build on Klipper. Klipper is Python and runs only on SoC (Linux) — never on an MCU host. FlowPulse is Rust, compiling to SoC and to MCUs like ESP32 alike.

Features

核心特性Core Features

为性能、精度与可靠性而设计的关键能力。Key capabilities engineered for performance, precision and reliability.

分体式四层架构Decoupled 4-Tier Architecture

前端 / 客户端 / 核心服务端 / 设备端各司其职，配置、运动规划与硬件控制彻底分离，职责清晰、易于扩展。Frontend, client, core server and device firmware each own a single responsibility — config, motion planning and hardware are cleanly separated.

高性能运动规划High-Performance Motion Planning

前瞻算法提前加减速，S-Curve / SixPoint 速度曲线，圆弧插补，让高速转弯更平滑、更精准。Look-ahead acceleration, S-Curve / SixPoint velocity profiles and arc interpolation for smoother, sharper high-speed corners.

双重智能补偿Dual Smart Compensation

热床调平（双线性 / 双三次 / 拉格朗日）+ 共振补偿（ZV / MZV / ZVD / EI 等 6 种整形器），消除条纹与抖动。Bed mesh leveling plus input shaping (ZV/MZV/ZVD/EI & more) to kill ringing and print artifacts.

端到端加密通信End-to-End Encrypted Link

上下位机运动指令经 AES-256-GCM 自动加解密，加密层对调用方透明，关键帧密钥可自动轮换。Motion commands between host and MCU are auto encrypted with AES-256-GCM — transparent to callers, with auto key rotation.

实时安全链Real-Time Safety Chain

温度越限、位置越界、硬件故障秒级检测，急停链路闭环到所有前端，状态机全程守护。Second-level detection of over-temperature, out-of-bounds and faults; an emergency-stop chain broadcasts to every frontend.

多端统一访问Multi-Surface Access

局域网 Web、机身触屏（LVGL）、云端 App（MQTT）三端共用一套状态与接口，实时推送无需刷新。LAN web, onboard touch HMI and cloud app share one state model with live push — no refresh needed.

Why FlowPulse

为什么选 FlowPulseWhy FlowPulse

与 Klipper 的中心化架构不同，FlowPulse 采用非中心化、分层的设计，可同时运行在 SoC 与单片机上，从而大幅降低硬件成本。最低只需两颗单片机即可跑通：上位机用 ESP32-S3，下位机用 GD32F303 或 STM32F407；还支持扩展喷头单片机（喷头开发目前仅在 STM32F103 上完成）。Unlike Klipper's centralized design, FlowPulse is decentralized and layered, running on both SoC and MCU — sharply lowering hardware cost. A minimal build needs just two MCUs: an ESP32-S3 host and a GD32F303 or STM32F407 device; a toolhead MCU is also supported (toolhead work done so far only on STM32F103).

纯单片机方案Pure-MCU Path

类似某竹 A1 的硬件方案，廉价打印机无需外接 Linux 主机即可跑自研系统。Like the Bambu A1 hardware approach — cheap printers run a self-built system with no external Linux host.

极低内存占用Tiny Memory Footprint

运行在 SoC 时内存占用低，最小可支持 64 MB 内存即可稳定工作。On SoC it stays light — stable from as little as 64 MB RAM.

完全自主可控Fully Self-Developed

所有代码自主开发，从协议到固件全程可控，不依赖闭源中间层。Every layer is self-built — from protocol to firmware, with no reliance on closed middle layers.

单片机间硬同步MCU-to-MCU Sync

主单片机与喷头单片机通过单片机间同步协同，实时性更强，初步实测同步精度约 10+ μs，可显著提升打印精度。The main and toolhead MCUs sync via inter-MCU synchronization for tighter real-time response — early measurements show ~10+ μs sync precision, markedly improving print accuracy.

Motion Control

运动控制Motion Control

把一条 G-code 路径，变成电机精准的每一步脉冲。Turning a G-code path into precisely timed motor pulses.

前瞻与速度曲线Look-ahead & Velocity Profiles

前瞻队列提前查看前方若干段，按 S-Curve / SixPoint 规划加减速，避免急停急起，转弯更顺滑。A look-ahead queue inspects upcoming segments and shapes acceleration with S-Curve / SixPoint profiles to avoid jerky starts and stops.

Bresenham 插补Bresenham Interpolation

多轴整数闭式规划，逐轴精确算出每步时刻，与 E 轴同源算法保证双 MCU 脉冲同步。Per-axis integer closed-form stepping, aligned with the E-axis algorithm so dual-MCU pulses stay in sync.

TIMER 脉冲输出TIM6 Step Output

Klipper 式状态机在最高优先级 ISR 中输出脉冲，4 轴步进缓冲（512 事件环形队列）零丢步。A Klipper-style state machine emits pulses from the top-priority ISR; a 512-event ring buffer feeds 4 axes without missed steps.

圆弧与归零Arc & Homing

G2/G3 圆弧插补（弦高误差控制）+ 自动归零流程，让曲线与原点都精准可靠。G2/G3 arc interpolation with chord-error control plus an automated homing flow for reliable curves and origins.

Compensation

智能补偿Smart Compensation

两层算法，解决打印最常见的两类瑕疵：翘边与条纹。Two layers that fix the two most common flaws: poor first-layer adhesion and ringing.

热床调平补偿Bed Mesh Leveling

按喷嘴当前 XY 位置补偿 Z 高度，支持三种插值：Compensates Z by nozzle XY position, with three interpolators:

Bilinear 4 点4-pt — 快速线性fast linear
Bicubic 16 点16-pt — 平滑 C1 连续smooth C1
Lagrange 可变variable — 高阶精确high-order exact

共振补偿（Input Shaping）Resonance (Input Shaping)

过滤引发机器抖动的速度变化，支持 6 种整形器：Filters velocity changes that excite ringing — six shapers:

ZV 2 脉冲 · 基础pulses · base
MZV 3 脉冲 · 消速度残余pulses · kills velocity resid.
ZVD 3 脉冲 · 抗频偏pulses · freq-robust
EI 3 脉冲 · 宽抑制pulses · wide
2-Hump EI 4 脉冲 · 更宽pulses · wider
3-Hump EI 5 脉冲 · 最宽pulses · widest

Workflow

典型工作流Typical Workflows

正常打印Normal Print

1

网页上传 G-code，等温度到 200°C 开始逐条发送。Upload G-code on the web; once hotend hits 200°C, commands stream out.

2

核心服务端规划轨迹并加密下发，主板每 200ms 上报状态。Core server plans & encrypts; the board reports status every 200ms.

3

温度曲线经 WebSocket 实时推送到网页，无需刷新。Temperature curves push live over WebSocket — no refresh.

热床调平Bed Leveling

1

传感器触碰各点，记录高度网格。A probe touches points and records a height grid.

2

打印时按 XY 位置自动补偿 Z，第一层粘得牢。Z is auto-compensated by XY during print for a solid first layer.

安全保护Safety

1

每秒检查温度越限 / 越界 / 硬件故障。Per-second checks for over-temp, out-of-bounds, faults.

2

异常即急停、关加热，并通知所有前端。On fault: e-stop, heaters off, notify every frontend.

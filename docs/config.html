配置文件Configuration Files

FlowPulse 的所有运行参数都以 JSON 格式存放，按功能类别拆分到多个独立文件，便于按模块维护与备份。配置文件默认位于 All FlowPulse runtime parameters are stored as JSON, split by function into separate files for easy per-module maintenance and backup. Config files live under E:\3D-Printer\4.FlowPulse\config。.

硬件引脚配置有三个文件：hardware.json 为实际使用的主配置；hardware-STM32.json 与 hardware-GD32.json 是分别对应两颗主控芯片的备用备份，结构相同、仅引脚与驱动参数不同，换板时取对应文件覆盖即可。The hardware pin mapping has three files: hardware.json is the active config in use; hardware-STM32.json and hardware-GD32.json are backup variants for the two MCUs — same schema, only pins and driver params differ, swap in the matching file when changing boards.

文件总览File Overview

① 打印机与通信① Printer & Communication — printer.json

定义机型标识与上下位机通信方式：串口参数（端口、波特率、数据位、校验、停止位、超时）、状态上报间隔，以及 G-code 批处理大小。Printer model id and host↔device communication: serial params (port, baud rate, data bits, parity, stop bits, timeout), status-report interval, and G-code batch size.

② 硬件引脚与驱动② Hardware Pins & Drivers — hardware.json （主用）(active)

板级引脚与驱动映射：各轴电机（step/dir/enable、细分、电流、sensorless 归位）、限位开关、温度传感器、加热管、GPIO、风扇，以及热床调平网格。换主控时通常只改 hardware-STM32.json / hardware-GD32.json 中的引脚。Board-level pin and driver mapping: per-axis motors (step/dir/enable, microsteps, current, sensorless homing), limit switches, temperature sensors, heaters, GPIO, fans, and the bed-leveling mesh. When changing the MCU you usually only edit the pins in hardware-STM32.json / hardware-GD32.json.

③ 运动控制③ Motion Control — motion.json

运动学参数（最大速度/加速度/进给率/jerk）、junction 转角、segment 缓冲、归位、圆弧插补、挤出场压力提前（pressure advance）、六段速度曲线，以及共振补偿（input shaper）。Kinematics (max velocity/accel/feed-rate/jerk), junction deviation, segment buffering, homing, arc interpolation, extruder pressure advance, the six-point velocity profile, and resonance compensation (input shaper).

④ 温度与材料④ Temperature & Materials — temperature.json

材料预设（PLA / ABS / PETG 的喷嘴/热床温度与风扇）、温度安全检测、等待稳定条件、自动风扇启停，以及 PID 整定参数。Material presets (PLA / ABS / PETG hotend/bed temps and fan), temperature safety checks, settle-wait conditions, auto-fan on/off, and PID tuning parameters.

⑤ 安全保护⑤ Safety — safety.json

总开关、急停超时、运动范围限制，以及加热器温度故障/偏差的分级阈值与动作（告警 / 暂停 / 关闭 / 急停）。Master switch, emergency-stop timeout, motion range limits, and graded heater temperature-fault / deviation thresholds with actions (warn / pause / turn-off / emergency-stop).

⑥ 断点续打⑥ Resume / Checkpoint — resume.json

断点续打开关、检查点间隔、Z 抬升/回抽距离，以及当前检查点状态（层号、温度、进给/流量比例）。Resume on/off, checkpoint interval, Z-hop and retract distances, and the current checkpoint state (layer, temps, feed/flow ratios).

⑦ 日志诊断⑦ Logging & Diagnostics — logging.json

控制台与文件输出级别，以及按模块（温度/安全/MQTT/WebSocket…）单独设置日志等级，便于排查问题。Console and file output levels, plus per-module log levels (temperature / safety / MQTT / WebSocket …) for easier troubleshooting.

后续各章将针对用户最常改动的 ①②③④⑤ 给出字段级说明与修改示例。Later chapters will give field-level details and edit examples for the most-edited files ①②③④⑤.

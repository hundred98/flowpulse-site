运动控制Motion Control

本章介绍 FlowPulse 如何让高速打印更平滑、更精准：前瞻规划、加减速曲线、多轴同步与智能补偿，以及使用者如何在控制台调参。How FlowPulse keeps high-speed printing smooth and precise: look-ahead, velocity profiles, multi-axis sync, smart compensation, and where you tune them in the console.

前瞻运动规划Look-Ahead Planning

前瞻算法在打印前扫描后续路径，提前规划加减速，避免到了转弯处才急刹。这样高速转弯更平滑、更精准，减少抖动与表面波纹。Look-ahead scans upcoming paths before printing and plans acceleration in advance, so the printer doesn't slam the brakes at corners — smoother, sharper high-speed turns with less ringing.

加减速曲线与 jerk 限制Velocity Profiles & Jerk Limit

支持 S-Curve 与 SixPoint 速度曲线，并对 jerk（加加速度）做限制，使速度变化连续，机械冲击更小、运行噪声更低。Supports S-Curve and SixPoint velocity profiles with jerk limiting, keeping acceleration continuous for gentler mechanical stress and lower noise.

多轴同步Multi-Axis Sync

X/Y/Z/E 多轴在同一时间基准下协同插补，圆弧插补保证曲线段精度，避免各轴不同步导致的棱角失真。X/Y/Z/E axes interpolate on a shared time base; arc interpolation keeps curved segments precise and avoids corner distortion from desync.

智能补偿Smart Compensation

  • 热床调平Bed Leveling — 双线性 / 双三次 / 拉格朗日网格，修正平台不平整。Bilinear / bicubic / Lagrange mesh to correct an uneven bed.
  • 共振补偿（Input Shaper）Input Shaping — ZV / MZV / ZVD / EI 等整形器，抑制打印波纹与机架抖动。ZV / MZV / ZVD / EI shapers to kill ringing and frame wobble.

参数调优指引Tuning Guide

在控制台的「补偿」面板可设置调平网格密度与输入整形器类型 / 频率。默认值已适配常见机型；首次使用建议先做一次共振频率自动测定，再据此选择整形器。In the console's Compensation panel you set mesh density and the input-shaper type / frequency. Defaults fit common machines; on first run, run an auto resonance-frequency measurement, then pick a shaper from the result.

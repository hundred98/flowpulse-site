项目简介Introduction

FlowPulse 是一套协议开放、分体式四层的 3D 打印控制固件。它把「配置 / 运动规划 / 硬件控制」彻底分离：网页与触屏负责操作，上位机与核心服务端充当大脑，单片机负责执行。整条链路从网页指令一路贯通到电机脉冲，并对上下位机之间的运动指令做端到端加密。FlowPulse is an openly-protocoled, decoupled four-tier 3D printer control firmware. It cleanly separates configuration, motion planning and hardware control: web & touch handle operation, the host and core server act as the brain, and the MCU executes. The chain runs end-to-end from a web command down to motor pulses, with motion commands end-to-end encrypted between host and MCU.

项目定位与优势Positioning & Advantages

与 Klipper 的中心化架构不同，FlowPulse 采用非中心化、分层的设计，可同时运行在 SoC 与单片机上，从而大幅降低硬件成本。最低只需两颗单片机即可跑通：上位机用 ESP32-S3，下位机用 GD32F303 或 STM32F407；还支持扩展喷头单片机（喷头开发目前仅在 STM32F103 上完成）。Unlike Klipper's centralized design, FlowPulse is decentralized and layered, running on both SoC and MCU — which sharply lowers hardware cost. A minimal setup needs just two MCUs: an ESP32-S3 host and a GD32F303 or STM32F407 device; a toolhead MCU is also supported (toolhead work is done so far only on STM32F103).

  1. 支持纯单片机方案，类似某竹 A1 的硬件方案。Pure-MCU path, comparable to the 某竹 A1 hardware approach.
  2. 运行在 SoC 时内存占用低，最小可支持 64 MB 内存。On SoC it stays light — runs on as little as 64 MB RAM.
  3. 完全自主开发，所有代码可控。Fully self-developed; all code is under your control.
  4. 主单片机与喷头单片机之间采用单片机间同步，实时性更强，初步实测同步精度可达 10+ μs，可显著提升打印精度。The main and toolhead MCUs sync via inter-MCU synchronization for tighter real-time response — early measurements show sync precision around 10+ μs, markedly improving print accuracy.

四层架构一览Four Tiers at a Glance

  • 前端层Frontend — Web · HMI · App，用户的操作入口。Web · HMI · App — the operator's entry points.
  • FlowPulse 上位机Host — Rust 编写，可编译到 SoC / Windows·Linux / ESP32。Written in Rust, compiles to SoC / Windows·Linux / ESP32.
  • 核心服务端（Rust）Core Server (Rust) — 调度、前瞻运动规划、智能补偿、加密（细节待补充）。Scheduling, look-ahead planning, smart compensation, encryption (details TODO).
  • 设备端固件（C，STM32/GD32）Device Firmware (C, STM32/GD32) — 实时电机脉冲控制（细节待补充）。Real-time motor pulse control (details TODO).

快速开始Quick Start

  1. 准备硬件：一块 STM32/GD32 主控板 + 一台上位机（SoC、x86 电脑或 ESP32）。Prepare hardware: an STM32/GD32 control board plus a host (SoC, x86 PC or ESP32).
  2. 将设备端固件烧录到主控板。Flash the device firmware onto the control board.
  3. 在上位机启动 FlowPulse 服务。Start the FlowPulse service on the host.
  4. 同一局域网打开 Web 控制台即可操控打印机。Open the web console on the same LAN to control the printer.
